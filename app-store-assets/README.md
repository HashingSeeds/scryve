# App Store visuals

Upload the six `iphone-6.9/en-US/*.png` files to the English 6.9-inch iPhone screenshot slot. `iphone-6.9/en-US/preview.mp4` is the optional iPhone app preview.

Upload the five `ipad-13/en-US/*.png` files to the English 13-inch iPad screenshot slot. They are native 2064 × 2752 captures from an isolated iPad Pro 13-inch (M5) simulator. They show the six-player board, connected setup, Abzan Armor deck, local history, and game controls. Goldie 0.3.1 supports the iPhone and Play phone presets but has no iPad preset, so the iPad images are unframed app captures.

The Abzan Armor deck was seeded only in the isolated capture build from the [official 100-card list](https://magic.wizards.com/en/news/announcements/tarkir-dragonstorm-commander-decklists). That seed is not in the app source.
